# Шумоподавление речи с VAD

Учебный проект по обработке речи. Проверяем, помогает ли подавление фонового шума уменьшить число ошибок автоматического распознавания.

VAD отмечает участки речи. По паузам оцениваем спектр шума и ослабляем фон по всей записи с помощью спектрального вычитания.

## План первой версии

Команда принимает моно WAV с частотой 16 кГц и сохраняет обработанный WAV той же длительности. Интервалы `[start, end)` передаются в отсчётах входного сигнала. Если подходящих пауз нет, программа сообщает, что шум не удалось оценить.

Запланированный запуск

```bash
python denoise.py input.wav -o output.wav
```

## Эксперимент

Для каждой фразы сравниваем чистую запись, запись с добавленным шумом и две версии после очистки. Фильтр один и тот же. Меняется только способ оценки шума — по первым 0,5 секунды или по паузам, найденным VAD. Используем одну модель распознавания, считаем WER и слушаем примеры до и после.
